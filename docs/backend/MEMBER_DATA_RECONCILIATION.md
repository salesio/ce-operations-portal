# Member Data Reconciliation

Legacy data is not authoritative operational data. Review a staged row, match it to the correct Church → Cell Group → Cell hierarchy, confirm any duplicate candidate, and then explicitly choose whether it is a new member, an existing-member link, or a skip.

Never infer a death, transfer, leadership permission, donation, baptism, certificate or Foundation School enrolment from ambiguous historical text. Preserve unknown values and reconcile them through the owning module.
